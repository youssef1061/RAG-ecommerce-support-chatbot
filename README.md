# RAG-Based E-commerce Customer Support Chatbot

## NLP Final Task 2026

An integrated NLP customer-support chatbot that processes a customer message
through four modules:

1. Language Detection
2. Emotion Classification
3. Intent Classification
4. Retrieval-Augmented Generation (RAG)

The system detects message language, identifies emotional tone, predicts a
customer-support intent, retrieves relevant support information from a FAISS
vector index, and returns a grounded support response.

> Main runnable notebook: `NLP_Final_Task_2026.ipynb`
